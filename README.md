# TradeLab AI: A Flight Simulator for Traders (Starter)

A small full-stack paper-trading app. You get ₹10,00,000 of **virtual** cash and practise buying and selling stocks at **mock** prices.

> **Read this first**
> - Stock prices are **mock data** generated by the server. They are not live or real market prices.
> - All data (cash, holdings, trades) is stored **in memory on the backend**. It **resets every time the server restarts**.
> - This is a learning starter, **not production-ready**. There is no login, database, or AI feature yet.
> - No API keys, paid services, or database accounts are needed.

## 1. Prerequisites

1. **Node.js 18 or newer (LTS recommended)**: download from https://nodejs.org
2. **VS Code**: https://code.visualstudio.com

Check your install in PowerShell:

```powershell
node -v
npm -v
```

Both should print version numbers.

## 2. Extract and open the project

1. Right-click `tradelab-ai-starter.zip` and choose **Extract All...**
2. Open VS Code, then **File > Open Folder...** and choose the extracted `tradelab-ai-starter` folder.
3. Open a terminal inside VS Code: **Terminal > New Terminal**. You will need **two** terminals (use the `+` button for a second one).

## 3. Install dependencies (once)

In terminal 1 (backend):

```powershell
cd server
npm install
```

In terminal 2 (frontend):

```powershell
cd client
npm install
```

(If you are already inside `server` in the first terminal, do not `cd server` again. Use `cd ..\client` or open a fresh terminal at the project root.)

## 4. Run the app

**Terminal 1: backend**

```powershell
cd server
npm run dev
```

You should see: `TradeLab AI server running at http://localhost:4000`

**Terminal 2: frontend**

```powershell
cd client
npm run dev
```

You should see a line like `Local: http://localhost:5173/`

## 5. Open in your browser

- App: **http://localhost:5173**
- API health check: http://localhost:4000/api/health
- Example API data: http://localhost:4000/api/stocks

Keep both terminals running while you use the app. Press `Ctrl + C` in a terminal to stop it.

## API reference

| Method | URL | Description |
| --- | --- | --- |
| GET | `/api/health` | Server status |
| GET | `/api/stocks` | List of mock stocks |
| GET | `/api/stocks/:symbol` | One stock with 30 days of mock price history |
| GET | `/api/portfolio` | Cash, holdings, profit/loss |
| GET | `/api/trades` | Trade history (newest first) |
| POST | `/api/trades` | Body: `{ "symbol": "TCS", "side": "BUY", "quantity": 5 }` |

Trade rules enforced by the server:
- Quantity must be a whole number greater than 0.
- BUY is rejected if the order costs more than your virtual cash.
- SELL is rejected if you own fewer shares than you try to sell.
- Cash, holdings, and trade history are always updated together.

"Total profit/loss" = (cash + current value of holdings) - ₹10,00,000, so it includes both realized and unrealized profit/loss.

## Troubleshooting (Windows PowerShell)

**`npm : File ...npm.ps1 cannot be loaded because running scripts is disabled`**
Run once, then retry:
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

**`'node' is not recognized`**
Install Node.js, then close and reopen VS Code so it picks up the new PATH.

**`Cannot reach the server` or the app shows an error on load**
The backend is not running. Start it in `server` with `npm run dev` and click **Try again**.

**`Error: listen EADDRINUSE: address already in use :::4000`**
Something else uses port 4000. Find it with `netstat -ano | findstr :4000`, then stop it with `taskkill /PID <number> /F`. Or run the server on another port:
```powershell
$env:PORT=4001; npm run dev
```
If you change the port, also update the proxy target in `client/vite.config.ts`.

**Port 5173 is busy**
Vite will pick the next free port (for example 5174) and print it. If the browser then shows CORS errors on direct API calls, note that the app uses the Vite proxy, so it should still work; if not, add that port to the `cors` origin list in `server/src/index.ts`.

**`npm install` fails**
Check your internet connection, delete the `node_modules` folder and `package-lock.json` in that folder, and run `npm install` again.

**Blank page or red errors in the browser**
Open the browser console (F12), read the first error, and make sure both terminals are running without errors.

## Ideas for what to build next

The code is split so you can extend it step by step:
- Replace the in-memory `Map` and arrays in `tradingService.ts` with PostgreSQL + Prisma.
- Replace `data/stocks.ts` with a real market-data provider.
- Add an AI service as a new folder in `server/src/services/` and a new route.
- Add authentication so each user has their own portfolio.

Push to GitHub with `git init`, `git add .`, `git commit -m "Initial commit"`. The `.gitignore` already excludes `node_modules`.
